# M6-3 Airflow 일 배치 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 지금 사람이 CLI로 순서대로 돌리는 수집 → 파싱 → 그래프·알림 → 색인 → 게시 → 정리를 Airflow 3가 일정, 순서, 재시도, Pool, 실패 기록까지 맡아 매일 스스로 돌게 만든다(spec §1, §2).

**Architecture:**
- **배포**
  - 이 저장소 전용 Airflow 3.3.2 이미지 `nst-regulation/airflow:3.3.2`을 쓴다. 공식 이미지에 `reg` 패키지를 넣었다.
  - `infra/docker-compose.yml`에 `airflow-init`, `airflow-apiserver`(UI 21062), `airflow-scheduler`, `airflow-dag-processor`를 추가한다.
  - LocalExecutor를 쓴다. 메타 DB는 공유 PG(21055)의 별도 데이터베이스 `reg_airflow`다.
- **변환기(B안)**
  - HWP→PDF 변환기를 상주 HTTP 서비스 `converter`로 바꾼다. 외부와 끊긴 내부 네트워크 `convert`에만 둔다.
  - `reg.platform.convert.get_converter()`가 설정(`REG_CONVERTER_URL`)을 보고 고른다.
    - 값이 있으면 `HttpConverter`(compose 안)
    - 값이 없으면 `DockerConverter`(호스트 CLI)
- **DAG**
  - `airflow/dags/`의 DAG 9개는 얇다. 각 태스크는 overview §2.6 표의 `reg.<모듈>.tasks` 함수를 **태스크 함수 안에서** import해 부른다.
  - 그래서 다른 트랙이 아직 병합되지 않아도 DAG 파싱은 깨지지 않는다.
  - 공통 시간대, Asset, 재시도 묶음, 실패 콜백은 `airflow/dags/reg_common.py` 한 곳에 둔다.
- **운영 함수** (`reg.ops`)
  - `daily_summary()`: 하루 결과를 `ops.pipeline_run`에 남긴다.
  - `maintenance()`: 오래된 로그를 지우고, 옛 색인 정리를 M6-4의 `prune`에 맡긴다.
  - `record_task_failure()`: 실패 콜백이 부른다. 메일은 보내지 않는다(D-6).

**Tech Stack:**
- Airflow 3.3.2 (Task SDK `airflow.sdk`, FAB 인증 관리자, LocalExecutor)
- Docker Compose v5, PostgreSQL 16 (공유 `nais-postgres-1`)
- LibreOffice + H2Orestart (변환기), Python 표준 `http.server`
- httpx + respx, testcontainers

**Spec:** `docs/superpowers/specs/2026-10-02-batch-pipeline-design.md` (§1, §2, §6.2, §8, §9, 결정 D-1·D-2·D-6·D-7)
**계약:** `docs/superpowers/plans/2026-10-02-m6-overview.md` (§2.5 `ops.pipeline_run`, §2.6 `tasks.py` 표, §3 공유 파일 규칙, §4 실서버 원칙)

## Global Constraints

- **Airflow**
  - 버전: `apache/airflow:3.3.2-python3.13`(PyPI 최신 안정판, 2026-10-02 확인). 이미지 태그는 `nst-regulation/airflow:3.3.2`.
  - 실행 방식: `AIRFLOW__CORE__EXECUTOR=LocalExecutor`. Celery·Kubernetes는 쓰지 않는다.
  - 메타 DB: `postgresql+psycopg2://reg_airflow:${REG_AIRFLOW_DB_PASSWORD}@postgres:5432/reg_airflow`
  - UI: 호스트 `21062` → 컨테이너 `8080`
  - 시간대: `Asia/Seoul`. DAG 일정은 모두 KST cron이다.
- **DAG 규칙** (모든 DAG)
  - `max_active_runs=1`, `catchup=False`
  - 새 DAG는 일시정지 상태로 올라온다(`DAGS_ARE_PAUSED_AT_CREATION=true`). 켜는 일은 통합 단계에서 한다.
- **DAG import**
  - DAG 파일 최상위에서 `reg`를 import하지 않는다.
  - 태스크 함수 안에서 overview §2.6 표의 함수만 import한다.
  - 예외는 하나다. 실패 콜백이 `reg.ops.failures.record_task_failure`를 지연 import한다.
- **재시도·시간 상한** (spec §2.3)

  | 단계 | 재시도 | 실행 시간 상한 |
  |---|---|---|
  | 수집 | 3회, 지수 백오프 5분부터 | 기관당 60분 (법령 일 배치 120분, 법령 전체 12시간) |
  | 파싱 | 1회 | 120분 |
  | 색인 | 6회, 30분 간격 | 90분 |

- **Pool**: `alio_pool`=2, `lawgo_pool`=1, `gpu_pool`=1. `airflow-init`이 만든다.
- **실패 알림**
  - `on_failure_callback`이 `ops.pipeline_run`에 `status='failed'`, `stats.source='on_failure_callback'` 행을 남긴다.
  - 메일은 보내지 않는다(D-6).
- **비밀값**: `.env`의 `REG_*`만 쓴다. Airflow Connection·Variable에는 넣지 않는다.
- **컨테이너 안 주소**

  | 설정 | 값 |
  |---|---|
  | `REG_DATABASE_URL` | `${REG_DATABASE_URL_DOCKER}` (호스트 이름 `postgres:5432`) |
  | `REG_S3_ENDPOINT` | `http://storage:8333` |
  | `REG_OS_URL` | `http://opensearch:9200` |
  | `REG_NEO4J_URL` | `bolt://neo4j:7687` |
  | `REG_SMTP_HOST` / `REG_SMTP_PORT` | `mailpit` / `1025` |
  | `REG_CONVERTER_URL` | `http://converter:8080` |
  | GPU (`REG_EMBED_URL` 등) | `.env`의 `http://192.168.0.2:…`를 그대로 쓴다 |

- **공유 파일** (overview §3)
  - `infra/docker-compose.yml`은 이 트랙만 고친다.
  - `pyproject.toml`·`src/reg/wiring.py`·settings는 "추가만" 한다.
  - 프로젝트 전체에 `docker compose down`을 쓰지 않는다. storage·neo4j까지 내려간다.
- **실서버 원칙** (overview §4)
  - 테스트는 compose 서비스를 띄우지 않고 실 DB에 쓰지 않는다.
  - 테스트에서 허용하는 docker 사용은 세 가지다.
    - testcontainers
    - 일회용 `docker run --rm` (DAG 점검, 변환기 스모크)
    - `docker compose config`(검증만)
- **메시지**: 사용자에게 보이는 오류·로그·문서는 한국어로 쓴다. 코드 식별자는 영어로 쓴다.

## 이 계획의 결정 사항 (지시·spec이 정하지 않은 부분)

1. **`eval_smoke`는 넣지 않는다.**
   - overview §2.6 표에 평가 진입점이 없다. "표에 없는 함수를 DAG에서 부르지 않는다"는 규칙을 따른다.
   - 진입점이 표에 추가되면 `reg_publish`에 태스크 하나를 더한다.
2. **`reg_backfill`은 기관 수집만 한다.**
   - conf는 `{"institutions": ["KAERI"]}` 형태다.
   - 수집 결과로 Asset `regulation_raw`를 갱신하므로 파싱·게시는 뒤따라 자동으로 돈다.
   - 파서 변경 후 전체 재파싱(`rebuild`)은 §2.6에 진입점이 없다. 그래서 CLI `reg process --rebuild`로 하고 런북에 적는다.
3. **색인 게시 조건**
   - `index_build`가 돌려준 dict의 `release_id`를 `index_gate`·`index_publish`에 넘긴다.
   - 키가 없거나 `None`이면(변화 없는 날, 또는 M6-4 병합 전) 둘 다 **건너뜀**(실패 아님)으로 둔다.
   - M6-4의 `build()`는 `release_id`를 돌려줘야 한다(통합 시 확인).
4. **OCR 결과로 파싱을 다시 깨우는 조건**
   - `reg_ocr`는 `run_pending()` 결과의 `processed`가 1 이상일 때만 Asset `regulation_ocr`를 갱신한다. 이것이 `reg_process`를 다시 깨운다.
   - `processed`가 0이거나 키가 없으면 건너뛴다. 그러면 `reg_process` → `reg_ocr` → `reg_process` 무한 반복이 생기지 않는다.
   - 키가 없을 때의 손실은 지연뿐이다. 다음 03:30 안전망이 처리한다.
5. **색인 사슬과 그래프 사슬은 서로 기다리지 않는다.**
   - `graph_sync → alerts_scan`과 `embed_check → index_build → index_gate → index_publish`를 따로 둔다.
   - 그래프가 실패해도 검색 색인은 게시된다.
   - 두 사슬이 끝나면(`all_done`) `daily_summary`가 돈다.
6. **실패한 실행이 초록으로 보이지 않게 한다.**
   - `all_done` 태스크가 마지막에 있는 DAG(alio·backfill·process·publish)에는 `watcher` 태스크를 둔다. `trigger_rule="one_failed"`이고, 실행되면 바로 실패한다.
   - 그래서 상위 태스크 하나라도 실패하면 DAG 실행이 실패로 표시된다.
7. **하루 요약의 실패 수는 최종 실패만 센다.** `stats.source='on_failure_callback'` 행만 센다. 재시도 끝에 성공한 시도는 세지 않는다.
   - 요약 행은 `dag_id='reg_summary'`, `run_id='summary:YYYY-MM-DD'`로 하루 1행이다. 다시 돌리면 교체한다.
8. **`reg` 설치 방식**
   - Airflow 3.3.2는 `fastapi<0.137`을 요구한다. `reg`는 `fastapi>=0.142.2`를 요구한다.
   - 그래서 이미지에는 `reg`를 `--no-deps -e`로 설치한다. 배치 실행에 필요한 의존성은 `infra/airflow/requirements-batch.txt`로 Airflow constraints 아래에서 설치한다. fastapi·uvicorn은 뺀다.
   - 배치 import 경로에 fastapi가 들어오면 점검 스크립트가 실패한다.
9. **이미지 안 경로는 저장소 배치를 따른다.**
   - 코드는 `/opt/nst-regulation/src`에 굽는다. 코드가 바뀌면 이미지를 다시 빌드한다.
   - `config/`와 `airflow/dags/`는 읽기 전용으로 마운트한다. 기관 추가와 DAG 수정은 재빌드 없이 반영된다.
   - 코드가 `Path(__file__).parents[…]`로 `config/`를 찾으므로 이 배치가 필요하다.
10. **GPU(192.168.0.2) 접근**
    - Docker 브리지 네트워크의 외부 통신은 호스트 NAT를 거친다. 그래서 GPU PC에는 출발지가 호스트(192.168.0.3)로 보인다. 호스트가 닿으면 컨테이너도 닿으며, 별도 설정이 필요 없다.
    - `nais_default`는 `internal: false`(확인함)다.
    - 브리지 대역(172.17~172.21)은 LAN 192.168.0.0/24와 겹치지 않는다.
    - law.go.kr OC 키의 등록 IP(공인 116.43.250.15)도 같은 NAT로 나간다.
    - 통합 단계에서 컨테이너 안에서 `GET /v1/models`로 실제 확인한다.
11. **변환기 네트워크와 동시성**
    - 변환기는 `internal: true` 네트워크 `convert`에만 둔다. 포트를 공개하지 않고 외부 인터넷에도 닿지 않는다. 기존 `docker run --network none`과 같은 격리다.
    - 같은 LibreOffice 프로필을 쓰므로 한 번에 하나씩 변환한다.
    - 이미지 태그를 `0.2`로 올린다. ENTRYPOINT는 그대로 두므로 `DockerConverter`도 같은 이미지를 쓴다.
12. **UI 포트**: 21062는 21060·21061과 같이 모든 인터페이스에 연다(LAN의 사용자 PC에서 접속). FAB 로그인으로 보호한다.

## Review Focus

1. **한 기관만 수집이 실패한 날**
   - 기대 동작
     - 나머지 기관의 파일은 파싱까지 간다(`regulation_raw` 갱신).
     - 폐지 대조는 정상 종료된 기관 결과만 받는다.
     - DAG 실행은 실패로 보인다.
   - 테스트: Task 8 점검 스크립트가 trigger rule을 검사하고 `reconcile([None, None])`을 직접 실행한다.
   - 남는 위험: 실패한 매핑 인덱스가 `reconcile` 입력에서 어떻게 빠지는지는 통합 단계 Task 10에서 실제 실행으로 확인한다.
2. **GPU PC가 꺼진 날**
   - 기대 동작
     - `embed_check`가 30분 간격으로 6회 재시도한다.
     - 그동안 그래프·알림·하루 요약은 진행된다.
     - 검색은 이전 release로 계속 동작한다.
   - 테스트: Task 8에서 재시도 간격, `gpu_pool`, `daily_summary`의 `all_done`을 검사한다.
3. **변화 없는 날 / OCR 할 것이 없는 날**
   - 기대 동작
     - `index_gate`·`index_publish`와 `reg_ocr.announce`가 실패가 아니라 건너뜀이 된다.
     - `reg_process`를 다시 깨우지 않는다.
   - 테스트: Task 8에서 태스크 callable을 직접 불러 `AirflowSkipException`을 확인한다.
4. **실패 기록 자체가 실패할 때 (주 DB 다운)**
   - 기대 동작: 콜백이 예외를 내지 않고 로그만 남긴다. Airflow 콜백 예외가 다른 실패를 가리면 안 된다.
   - 테스트: Task 8에서 닫힌 포트를 DSN으로 주고 `record_failure`를 부른다.
5. **변환기 컨테이너가 재시작 중이거나 내려간 때**
   - 기대 동작
     - 연결 실패를 몇 번 다시 시도한다.
     - 끝내 안 되면 `ConversionError`로 알린다. 그러면 보기용 PDF만 실패로 남고 조문 파싱은 계속된다.
     - 다른 예외로 새어 나가 이벤트 전체가 실패하면 안 된다.
   - 테스트: Task 5.

### Task 1: 실행 기록 `task_run`과 실패 기록 `record_task_failure`

**Files:**
- Modify: `src/reg/platform/runs.py` (M6-0에 `task_run`이 없을 때만 추가)
- Create: `src/reg/ops/failures.py`
- Create: `tests/ops/__init__.py` (빈 파일), `tests/ops/conftest.py`, `tests/ops/test_task_run.py`, `tests/ops/test_failures.py`

**Interfaces:**
- Consumes
  - `ops.pipeline_run(id bigserial, dag_id, run_id, task_id, started_at default now(), finished_at, status default 'running', stats jsonb default '{}', error)` (0008, M6-0)
  - `reg.platform.settings.get_settings().database_url`

# --- Airflow·CLI 공통 실행 기록 (ops.pipeline_run, overview §2.6) ---
import json as _json
import logging as _logging
import os as _os
from collections.abc import Iterator as _Iterator
from contextlib import contextmanager as _contextmanager
from datetime import UTC as _UTC
from datetime import datetime as _datetime

import psycopg as _psycopg

from reg.platform.settings import get_settings as _get_settings

_log = _logging.getLogger(__name__)


def _run_ids(name: str) -> tuple[str, str, str]:
    dag_id = _os.environ.get("AIRFLOW_CTX_DAG_ID") or "cli"
    run_id = _os.environ.get("AIRFLOW_CTX_DAG_RUN_ID") or f"cli:{_datetime.now(_UTC):%Y%m%dT%H%M%S}"
    task_id = _os.environ.get("AIRFLOW_CTX_TASK_ID") or name
    return dag_id, run_id, task_id


def _finish_task_run(dsn: str, rid: int, status: str, stats: dict, error: str | None) -> None:
    with _psycopg.connect(dsn, autocommit=True, connect_timeout=10) as c:
        c.execute("UPDATE ops.pipeline_run SET finished_at = now(), status = %s, stats = %s, error = %s WHERE id = %s",
                  (status, _json.dumps(stats, ensure_ascii=False, default=str), error, rid))


@_contextmanager
def task_run(name: str, *, dsn: str | None = None) -> _Iterator[dict]:
    """ops.pipeline_run 한 행으로 실행을 기록한다. 본문은 넘겨받은 dict에 결과를 채운다.

    시작·끝 기록은 짧은 autocommit 연결로 따로 한다: 본문 트랜잭션이 롤백돼도, 몇 시간짜리 태스크라도 기록은 남는다.
    """
    dsn = dsn or _get_settings().database_url
    dag_id, run_id, task_id = _run_ids(name)
    with _psycopg.connect(dsn, autocommit=True, connect_timeout=10) as c:
        rid = c.execute("INSERT INTO ops.pipeline_run (dag_id, run_id, task_id) VALUES (%s, %s, %s) RETURNING id",
                        (dag_id, run_id, task_id)).fetchone()[0]
    stats: dict = {}
    try:
        yield stats
    except BaseException as e:
        try:
            _finish_task_run(dsn, rid, "failed", stats, f"{type(e).__name__}: {e}"[:4000])
        except Exception:
            _log.exception("pipeline_run 실패 기록을 남기지 못함 (id=%s)", rid)
        raise
    _finish_task_run(dsn, rid, "succeeded", stats, None)
```

# src/reg/ops/tasks.py
"""운영 진입점: 하루 요약, 정리 작업 (overview §2.6, spec §8·§9). Airflow와 CLI(reg ops)가 같이 부른다."""
from __future__ import annotations

import json
from datetime import date, datetime, time, timedelta
from zoneinfo import ZoneInfo

from reg.ops.failures import FAILURE_SOURCE
from reg.platform.db.conn import connect
from reg.platform.runs import task_run
from reg.platform.settings import get_settings

KST = ZoneInfo("Asia/Seoul")
SUMMARY_DAG = "reg_summary"
HOLD_ATTEMPTS = 3  # core 처리기의 MAX_ATTEMPTS: 이만큼 실패한 이벤트는 보류(검수 화면)


def _window(day: date) -> dict:
    lo = datetime.combine(day, time.min, tzinfo=KST)
    return {"lo": lo, "hi": lo + timedelta(days=1)}


def collect_summary(conn, day: date) -> dict:
    w = _window(day)
    docs = {r["source"]: r["n"] for r in conn.execute(
        "SELECT source, count(*) AS n FROM regulation.source_document"
        " WHERE fetched_at >= %(lo)s AND fetched_at < %(hi)s GROUP BY source ORDER BY source", w)}
    runs = {r["source"]: {"runs": r["runs"], "failed": r["failed"]} for r in conn.execute(
        "SELECT source, count(*) AS runs, count(*) FILTER (WHERE status = 'failed') AS failed FROM ops.fetch_run"
        " WHERE started_at >= %(lo)s AND started_at < %(hi)s GROUP BY source ORDER BY source", w)}
    new_versions = conn.execute(
        "SELECT count(*) AS n FROM regulation.work_version WHERE created_at >= %(lo)s AND created_at < %(hi)s",
        w).fetchone()["n"]
    failed = [r["t"] for r in conn.execute(
        "SELECT DISTINCT dag_id || '.' || task_id AS t FROM ops.pipeline_run"
        " WHERE status = 'failed' AND stats->>'source' = %(src)s AND started_at >= %(lo)s AND started_at < %(hi)s"
        " ORDER BY 1", {**w, "src": FAILURE_SOURCE})]
    held = conn.execute("SELECT count(*) AS n FROM ops.outbox WHERE processed_at IS NULL AND attempts >= %s",
                        (HOLD_ATTEMPTS,)).fetchone()["n"]
    review = conn.execute(
        "SELECT count(*) FILTER (WHERE created_at >= %(lo)s AND created_at < %(hi)s) AS new,"
        " count(*) FILTER (WHERE status = 'OPEN') AS open FROM regulation.review_task", w).fetchone()
    impacts = {r["severity"]: r["n"] for r in conn.execute(
        "SELECT severity, count(*) AS n FROM ops.change_impact WHERE created_at >= %(lo)s AND created_at < %(hi)s"
        " GROUP BY severity ORDER BY severity", w)}
    abolished = conn.execute(
        "SELECT count(*) AS n FROM regulation.work WHERE status = 'ABOLISHED_CANDIDATE'").fetchone()["n"]
    rel = conn.execute(
        "SELECT id, os_index, published_at FROM ops.release WHERE state = 'PUBLISHED'"
        " AND published_at >= %(lo)s AND published_at < %(hi)s ORDER BY published_at DESC LIMIT 1", w).fetchone()
    return {
        "day": day.isoformat(),
        "collected": {"documents": docs, "runs": runs},
        "new_versions": new_versions,
        "failures": {"tasks": failed, "held_events": held},
        "review_queue": {"new": review["new"], "open": review["open"]},
        "impacts": impacts,
        "abolished_candidates": abolished,
        "release": None if rel is None else {
            "id": rel["id"], "os_index": rel["os_index"], "published_at": rel["published_at"].isoformat()},
    }


def save_summary(conn, summary: dict) -> None:
    run_id = f"summary:{summary['day']}"
    conn.execute("DELETE FROM ops.pipeline_run WHERE dag_id = %s AND run_id = %s", (SUMMARY_DAG, run_id))
    conn.execute("INSERT INTO ops.pipeline_run (dag_id, run_id, task_id, finished_at, status, stats)"
                 " VALUES (%s, %s, 'daily_summary', now(), 'succeeded', %s)",
                 (SUMMARY_DAG, run_id, json.dumps(summary, ensure_ascii=False)))


def daily_summary(day: str | None = None) -> dict:
    d = date.fromisoformat(day) if day else datetime.now(KST).date()
    with task_run("reg.ops.tasks.daily_summary") as stats:
        conn = connect(get_settings().database_url)
        try:
            summary = collect_summary(conn, d)
            save_summary(conn, summary)
            conn.commit()
        finally:
            conn.close()
        stats.update(summary)
    return summary
```

```python
def prune_log_files(root: Path, days: int = AIRFLOW_LOG_DAYS, now: float | None = None) -> int:
    """mtime이 days일 넘은 파일만 지운다. 폴더는 남긴다(실행 중인 태스크가 막 만든 빈 폴더를 지우지 않으려고)."""
    if not root.is_dir():
        return 0
    cutoff = (now if now is not None else _time.time()) - days * 86400
    n = 0
    for p in root.rglob("*"):
        if p.is_file() and p.stat().st_mtime < cutoff:
            p.unlink()
            n += 1
    return n


def _prune_indexes() -> dict:
    """옛 release 색인 삭제는 M6-4의 reg.index.tasks.prune이 맡는다. 아직 없으면 건너뛴다."""
    try:
        mod = importlib.import_module("reg.index.tasks")
    except ModuleNotFoundError as e:
        if (e.name or "").startswith("reg.index"):
            return {"skipped": "reg.index.tasks 없음"}
        raise
    prune = getattr(mod, "prune", None)
    if prune is None:
        return {"skipped": "reg.index.tasks.prune 없음 (M6-4 병합 전)"}
    return prune()


def maintenance() -> dict:
    s = get_settings()
    with task_run("reg.ops.tasks.maintenance") as stats:
        conn = connect(s.database_url)
        try:
            rl = conn.execute("DELETE FROM ops.request_log WHERE at < now() - make_interval(days => %s)",
                              (REQUEST_LOG_DAYS,)).rowcount
            qa = conn.execute("DELETE FROM ops.qa_log WHERE created_at < now() - make_interval(days => %s)",
                              (QA_LOG_DAYS,)).rowcount
            conn.commit()
        finally:
            conn.close()
        stats.update(request_log_deleted=rl, qa_log_deleted=qa)
        stats["airflow_logs_deleted"] = prune_log_files(Path(s.airflow_log_dir)) if s.airflow_log_dir else 0
        stats["index_prune"] = _prune_indexes()
    return dict(stats)

# infra/converter/server.py
"""HWP·HWPX → 보기용 PDF 변환 HTTP 서비스 (compose 내부 전용, 표준 라이브러리만: 이미지의 python3 = Debian 3.11).

POST /convert?kind=hwp|hwpx  본문=원본 바이트 → 200 application/pdf
GET  /healthz                → 200 ok
"""
import os
import signal
import subprocess
import sys
import tempfile
import threading
from http.server import BaseHTTPRequestHandler, ThreadingHTTPServer
from pathlib import Path
from urllib.parse import parse_qs, urlparse

KINDS = ("hwp", "hwpx")
MAX_BYTES = int(os.environ.get("CONVERTER_MAX_BYTES", str(50 * 1024 * 1024)))
TIMEOUT = float(os.environ.get("CONVERTER_TIMEOUT", "120"))
PROFILE = os.environ.get("CONVERTER_PROFILE", "file:///tmp/lo-profile")
_lock = threading.Lock()  # LibreOffice 프로필 하나를 함께 쓰므로 한 번에 하나씩 변환한다


class ConvertFailed(Exception):
    pass


class ConvertTimeout(Exception):
    pass


def soffice(src: Path, outdir: Path) -> bytes:
    cmd = ["soffice", f"-env:UserInstallation={PROFILE}", "--headless", "--norestore",
           "--convert-to", "pdf", "--outdir", str(outdir), str(src)]
    p = subprocess.Popen(cmd, stdout=subprocess.PIPE, stderr=subprocess.PIPE, start_new_session=True)
    try:
        _, err = p.communicate(timeout=TIMEOUT)
    except subprocess.TimeoutExpired:
        os.killpg(p.pid, signal.SIGKILL)  # soffice는 soffice.bin을 자식으로 띄운다: 프로세스 그룹째 끝낸다
        p.communicate()
        raise ConvertTimeout(f"{TIMEOUT:.0f}초 안에 끝나지 않음") from None
    out = outdir / f"{src.stem}.pdf"
    if p.returncode != 0 or not out.exists():
        raise ConvertFailed(f"rc={p.returncode} {err.decode(errors='replace')[-300:]}")
    pdf = out.read_bytes()
    if not pdf.startswith(b"%PDF"):
        raise ConvertFailed("변환 결과가 PDF가 아님")
    return pdf


def convert(data: bytes, kind: str) -> bytes:
    with _lock, tempfile.TemporaryDirectory() as d:
        src = Path(d) / f"in.{kind}"
        src.write_bytes(data)
        return soffice(src, Path(d) / "out")


class Handler(BaseHTTPRequestHandler):
    server_version = "nst-converter/0.2"
    convert = staticmethod(convert)

    def _reply(self, code: int, body: bytes, ctype: str = "text/plain; charset=utf-8") -> None:
        self.send_response(code)
        self.send_header("Content-Type", ctype)
        self.send_header("Content-Length", str(len(body)))
        self.end_headers()
        self.wfile.write(body)

    def do_GET(self) -> None:  # noqa: N802
        if urlparse(self.path).path == "/healthz":
            self._reply(200, b"ok")
        else:
            self._reply(404, b"not found")

    def do_POST(self) -> None:  # noqa: N802
        u = urlparse(self.path)
        if u.path != "/convert":
            return self._reply(404, b"not found")
        kind = (parse_qs(u.query).get("kind") or [""])[0]
        if kind not in KINDS:
            return self._reply(400, f"kind는 {'|'.join(KINDS)} 중 하나".encode())
        length = self.headers.get("Content-Length")
        if length is None:
            return self._reply(411, b"Content-Length required")
        try:
            n = int(length)
        except ValueError:
            return self._reply(400, b"bad Content-Length")
        if n <= 0:
            return self._reply(400, "본문이 비었음".encode())
        if n > MAX_BYTES:
            return self._reply(413, "파일이 너무 큼".encode())
        data = self.rfile.read(n)
        try:
            pdf = type(self).convert(data, kind)
        except ConvertTimeout as e:
            return self._reply(504, str(e).encode())
        except ConvertFailed as e:
            return self._reply(422, str(e).encode())
        self._reply(200, pdf, "application/pdf")

    def log_message(self, fmt: str, *args) -> None:
        sys.stderr.write("converter %s - %s\n" % (self.address_string(), fmt % args))


def main() -> None:
    port = int(os.environ.get("CONVERTER_PORT", "8080"))
    ThreadingHTTPServer(("0.0.0.0", port), Handler).serve_forever()


if __name__ == "__main__":
    main()
```

```python
CONVERT_KINDS = ("hwp", "hwpx")


class HttpConverter:
    """상주 변환기 서비스(infra/converter/server.py)를 부른다. compose 안(Airflow)에서 쓴다 (spec D-2 B안)."""

    def __init__(self, base_url: str, timeout: float = 180.0, tries: int = 3, wait: float = 2.0):
        self.base_url, self.timeout, self.tries, self.wait = base_url.rstrip("/"), timeout, tries, wait

    def to_pdf(self, data: bytes, ext: str) -> bytes:
        if ext not in CONVERT_KINDS:
            raise ConversionError(f"변환할 수 없는 형식: {ext}")
        last: Exception | None = None
        for i in range(self.tries):
            try:
                r = httpx.post(f"{self.base_url}/convert", params={"kind": ext}, content=data,
                               headers={"Content-Type": "application/octet-stream"}, timeout=self.timeout)
                break
            except (httpx.ConnectError, httpx.ConnectTimeout) as e:  # 변환기 재시작 중일 수 있다
                last = e
                if i + 1 < self.tries:
                    time.sleep(self.wait)
            except httpx.HTTPError as e:
                raise ConversionError(f"변환기 호출 실패: {e!r}") from e
        else:
            raise ConversionError(f"변환기에 연결할 수 없음 ({self.base_url}): {last!r}") from last
        if r.status_code != 200:
            raise ConversionError(f"변환 실패 (HTTP {r.status_code}): {r.text[:300]}")
        if not r.content.startswith(b"%PDF"):
            raise ConversionError("변환 결과가 PDF가 아님")
        return r.content


def get_converter(settings: Settings | None = None) -> Converter:
    s = settings or get_settings()
    return HttpConverter(s.converter_url) if s.converter_url else DockerConverter()
```

# tests/dags/test_dag_contract.py
"""DAG 파일 계약: 최상위에서 reg를 import하지 않고, 태스크 안에서는 overview §2.6 표의 함수만 부른다."""
import ast
from pathlib import Path

DAGS = Path(__file__).resolve().parents[2] / "airflow" / "dags"
DAG_IDS = {"reg_law_daily", "reg_law_full", "reg_alio_daily", "reg_process", "reg_publish", "reg_ocr",
           "reg_notify", "reg_maintenance", "reg_backfill"}
ALLOWED = {
    "reg.sources.alio.tasks": {"active_institutions", "collect_institution", "reconcile"},
    "reg.sources.lawgo.tasks": {"sync_daily", "sync_full", "link", "promote"},
    "reg.core.ingest.tasks": {"process_all", "quality_summary"},
    "reg.ocr.tasks": {"run_pending"},
    "reg.graph.tasks": {"sync"},
    "reg.alerts.tasks": {"scan", "notify"},
    "reg.index.tasks": {"embed_check", "build", "gate", "publish", "prune"},
    "reg.ops.tasks": {"daily_summary", "maintenance"},
    "reg.ops.failures": {"record_task_failure"},   # M6-3 자체 실패 콜백
}


def _is_reg(mod: str | None) -> bool:
    return bool(mod) and (mod == "reg" or mod.startswith("reg."))


def _module_level(nodes):
    for n in nodes:
        if isinstance(n, (ast.FunctionDef, ast.AsyncFunctionDef, ast.ClassDef)):
            continue
        yield n
        for field in ("body", "orelse", "finalbody", "handlers"):
            yield from _module_level(getattr(n, field, None) or [])


def _trees():
    return {p.stem: ast.parse(p.read_text(encoding="utf-8")) for p in sorted(DAGS.glob("*.py"))}


def test_dag_files_present():
    assert set(_trees()) == DAG_IDS | {"reg_common"}
    assert (DAGS / ".airflowignore").read_text().split() == ["reg_common.py"]


def test_no_reg_import_at_module_level():
    for name, tree in _trees().items():
        for n in _module_level(tree.body):
            if isinstance(n, ast.ImportFrom):
                assert not _is_reg(n.module), f"{name}: 최상위 import {n.module}"
            if isinstance(n, ast.Import):
                assert not any(_is_reg(a.name) for a in n.names), f"{name}: 최상위 import"


def test_lazy_imports_follow_contract():
    for name, tree in _trees().items():
        for n in ast.walk(tree):
            if isinstance(n, ast.Import):
                assert not any(_is_reg(a.name) for a in n.names), f"{name}: 'import reg…' 대신 from-import"
            if isinstance(n, ast.ImportFrom) and _is_reg(n.module):
                assert n.module in ALLOWED, f"{name}: 계약 밖 모듈 {n.module}"
                names = {a.name for a in n.names}
                assert names <= ALLOWED[n.module], f"{name}: 계약 밖 함수 {names - ALLOWED[n.module]}"


def test_each_file_defines_and_instantiates_its_dag():
    for dag_id in DAG_IDS:
        tree = _trees()[dag_id]
        funcs = [n for n in tree.body if isinstance(n, ast.FunctionDef)]
        assert [f.name for f in funcs] == [dag_id]
        assert any(isinstance(d, ast.Call) and getattr(d.func, "id", "") == "dag" for d in funcs[0].decorator_list)
        last = tree.body[-1]
        assert isinstance(last, ast.Expr) and isinstance(last.value, ast.Call) and last.value.func.id == dag_id

    from airflow.timetables.trigger import CronTriggerTimetable

    from airflow.sdk.exceptions import AirflowSkipException

    from airflow.exceptions import AirflowSkipException

def failure_fields(context) -> dict:
    ti = context["ti"]
    exc = context.get("exception")
    return {"dag_id": ti.dag_id, "run_id": ti.run_id, "task_id": ti.task_id,
            "map_index": getattr(ti, "map_index", -1), "try_number": getattr(ti, "try_number", None),
            "error": f"{type(exc).__name__}: {exc}" if exc is not None else "알 수 없는 실패"}


def record_failure(context) -> None:
    """마지막 재시도까지 실패한 태스크를 ops.pipeline_run에 남긴다. 메일은 보내지 않는다(D-6). 예외를 내지 않는다."""
    try:
        from reg.ops.failures import record_task_failure

        record_task_failure(**failure_fields(context))
    except Exception:
        log.exception("ops.pipeline_run에 실패 기록을 남기지 못함")


DEFAULT_ARGS = {"owner": "nst-regulation", "retries": 1, "retry_delay": timedelta(minutes=5),

COLLECT = {"retries": 3, "retry_delay": timedelta(minutes=5), "retry_exponential_backoff": True,

ONCE = {"retries": 1, "retry_delay": timedelta(minutes=5), "execution_timeout": timedelta(minutes=30)}
MARK = {"retries": 0, "execution_timeout": timedelta(minutes=5)}


def cron(expr: str) -> CronTriggerTimetable:
    return CronTriggerTimetable(expr, timezone=TZ)


def cron_or_assets(expr: str, assets) -> AssetOrTimeSchedule:
    return AssetOrTimeSchedule(timetable=cron(expr), assets=assets)


def dag_kwargs(doc: str | None) -> dict:
    return {"start_date": START, "catchup": False, "max_active_runs": 1, "default_args": DEFAULT_ARGS,
            "tags": ["nst-regulation"], "doc_md": doc}

    raise AirflowSkipException(reason)

        return run(finished)

    def done() -> None:
        return None

    results = collect.expand(code=codes)
    rec = reconcile(results)
    fin = done()
    rec >> fin

    @task(**ONCE)
    def targets() -> list[str]:
        wanted = [str(c).strip() for c in (get_current_context()["params"].get("institutions") or []) if str(c).strip()]
        if not wanted:
            raise ValueError('conf.institutions에 기관 코드를 하나 이상 넣으세요 (예: {"institutions": ["KAERI"]})')
        from reg.sources.alio.tasks import active_institutions

        unknown = sorted(set(wanted) - set(active_institutions()))
        if unknown:
            raise ValueError(f"활성 기관이 아님: {unknown} — config에 추가했는지 확인하세요")
        return wanted

    @task(pool="alio_pool", **COLLECT)
    def collect(code: str) -> dict:
        from reg.sources.alio.tasks import collect_institution

        return collect_institution(code)

    @task(trigger_rule="all_done", outlets=[RAW], **MARK)
    def done() -> None:
        return None

    codes = targets()
    results = collect.expand(code=codes)
    fin = done()
    results >> fin
    [codes, results, fin] >> watcher()


reg_backfill()

    except Exception as e:  # noqa: BLE001
        errors.append(f"record_failure가 DB 장애 때 예외를 냄: {e!r}")


def check_environment() -> None:

        "    except ModuleNotFoundError as e:\n"

        "            raise\n"
        "        missing.append(m)\n"

        errors.append("FAB 제공자가 없음 (AIRFLOW__CORE__AUTH_MANAGER)")

    return 0


if __name__ == "__main__":

```bash
#!/usr/bin/env bash
# scripts/airflow.sh — Airflow·변환기 compose 래퍼 (저장소 루트의 .env를 씀).
# 사용: scripts/airflow.sh build|up|down|ps|logs [서비스…]|init-db|check
# down은 Airflow·변환기만 멈춘다. 프로젝트 전체 `docker compose down`은 storage·neo4j까지 내리므로 쓰지 않는다.
set -euo pipefail
cd "$(dirname "$0")/.."
DC=(docker compose --env-file .env -f infra/docker-compose.yml)
RUN_SVCS=(converter airflow-apiserver airflow-scheduler airflow-dag-processor)
case "${1:-}" in
  build)   "${DC[@]}" build converter airflow-init ;;
  up)      "${DC[@]}" up -d airflow-init "${RUN_SVCS[@]}" ;;
  down)    "${DC[@]}" stop "${RUN_SVCS[@]}" ;;
  ps)      "${DC[@]}" ps converter airflow-init "${RUN_SVCS[@]}" ;;
  logs)    shift; if [ $# -eq 0 ]; then set -- airflow-scheduler; fi; "${DC[@]}" logs -f --tail=200 "$@" ;;
  init-db) bash scripts/airflow-metadata-db.sh ;;
  check)   bash scripts/airflow-check.sh ;;
  *) echo "사용법: $0 build|up|down|ps|logs [서비스…]|init-db|check" >&2; exit 2 ;;
esac
```

- 대상: 운영자. 배치 설계는 `docs/superpowers/specs/2026-10-02-batch-pipeline-design.md` §1·§2·§9.

## 구성

| 서비스 | 하는 일 |
|---|---|
